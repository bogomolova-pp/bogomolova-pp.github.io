# Git

Git — это распределенная система контроля версий (VCS), созданная Линусом Торвальдсом в 2005 году для управления исходным кодом.
Она фиксирует изменения в файлах, позволяя возвращаться к старым версиям, ветвить проекты и работать над ними совместно. Основной инструмент для IT-разработки, ускоряющий процесс создания ПО. 
Ключевые особенности Git:
    -Распределенность: У каждого разработчика есть локальная копия всего репозитория, что позволяет работать офлайн.
    -Скорость и безопасность: Git быстро работает и гарантирует целостность данных за счет хеширования.
    -Ветвление (Branching): Возможность создавать новые "ветки" для разработки фич без риска сломать основной код. 
    
Зачем нужен Git:

    -История изменений: Можно увидеть, кто, когда и что менял в файле.
    -Откат изменений: Легко вернуть проект к работоспособному состоянию после ошибки.
    -Совместная работа: Несколько человек могут одновременно редактировать один файл, а Git объединит их правки. 
    
    
Основные команды:

    git init: Создание нового репозитория.
    git clone: Клонирование существующего репозитория.
    git add: Добавление файлов в индекс (подготовка к коммиту).
    git commit: Сохранение изменений в локальной истории.
    git push: Отправка изменений в удаленный репозиторий (на GitHub).
    git pull: Получение обновлений из удаленного репозитория
